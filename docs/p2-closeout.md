# P2 收尾执行与验收清单

状态：2026-10-18 执行中。本文是 IMPLEMENTATION_PLAN.md 的 P2 收尾清单，不降低原验收要求；完成状态必须附实际证据。P3–P5 不在本次实现范围。执行者在每块完成后更新本文，受环境限制的验收明确保留为未通过，不能用 mock 或构建代替。

## 边界

KEEP：工程统一事务、稳定 ID、修订冲突、撤销/重做、控制/原始事件、全部 Agent 执行内核、扩展及授权。ADD：剩余音乐输入保护、控制器追溯与验收。REPLACE：已发现不正确的局部恢复/渲染实现，替代通过后方可移除旧路径。DELETE：无产品能力删除。无旧格式兼容、数据库迁移或无关重构。

输入范围是 P2 音乐编辑界面：通道/程序/片段位置长度、力度、播放位置/循环/音频驱动，以及已有时间图、命名对话框、指针预览。通用设置、附件及对话草稿沿用现状，不借此任务扩大为全应用表单持久化。已提交音乐仍只由 Go/SQLite 持有；未应用输入必须明确保留或由用户显式丢弃，恢复不得自动写音乐或更换原修订/目标。指针预览取消不提交，进行中阻止退出。

## 执行顺序与证据

1. [ ] 播放：检查固定 FluidSynth 2.6.1 源码和现有成功测试；补足 RPN/NRPN 及 mono/legato/portamento 的有序追溯，隔离轨道并彻底清理旧内部状态。验证 seek/loop/修订切换/停止、真实 PCM 和后续控制输入；声明重触发包络、尾音与滑音相位的实际边界，不承诺声学波形完全相等。
2. [ ] 输入：补足上述音乐表单的未应用保护，验证空值/非法值、切换、关闭、重开、冲突及失败路径。已应用输入不重复提交；恢复仅显式操作，不覆盖后来编辑。
3. [ ] 性能：在优化前测量 1k/10k 分散和同页密集音符；创建投影预算沿用 <200/<500ms。记录滚动、选择、编辑至可见结果和帧间隔；若超标，优先视口/片段裁剪并复测。不能通过丢弃源音符或隐瞒超标来勾选。
4. [ ] 原生完整流程：使用隔离数据目录和真实 Wails/WebKit 窗口验证离线新建/导入、多轨/片段/音符/时间图编辑、试听、撤销、保存重开、导出、原生选择器和退出保护；再做实际进程中断恢复。测试不得接触用户日常数据、密钥或其他进程。
5. [ ] 音频异常与安装：在隔离服务/设备上验证设备失联、重连与切换；不得停掉用户共享音频服务。检查发行动态依赖并测试隔离新用户数据启动。若缺少干净系统/物理回环设备，分别保留干净安装/物理延迟验收未通过，说明所缺条件。
6. [ ] 回归与文档：Go 测试、适用竞态测试、前端音乐/产品检查、桌面构建；通读本文件及受影响契约，更新实施计划、架构与 README 的完成范围，记录仍未通过的项目。

实际原生交互与真实音频输出需要分别证明；自动化能覆盖交互不代表人工听感或物理输出延迟已验收。真实系统断电不在共享机器上人为执行；其持久性不能凭进程终止推定。
