# P2 收尾执行与验收清单

状态：2026-10-18 执行中。本文是 IMPLEMENTATION_PLAN.md 的 P2 收尾清单，不降低原验收要求；完成状态必须附实际证据。P3–P5 不在本次实现范围。执行者在每块完成后更新本文，受环境限制的验收明确保留为未通过，不能用 mock 或构建代替。

## 边界

KEEP：工程统一事务、稳定 ID、修订冲突、撤销/重做、控制/原始事件、全部 Agent 执行内核、扩展及授权。ADD：剩余音乐输入保护、控制器追溯与验收。REPLACE：已发现不正确的局部恢复/渲染实现，替代通过后方可移除旧路径。DELETE：无产品能力删除。无旧格式兼容、数据库迁移或无关重构。

输入范围是 P2 音乐编辑界面：通道/程序/片段位置长度、力度、播放位置/循环/音频驱动，以及已有时间图、命名对话框、指针预览。通用设置、附件及对话草稿沿用现状，不借此任务扩大为全应用表单持久化。已提交音乐仍只由 Go/SQLite 持有；未应用输入必须明确保留或由用户显式丢弃，恢复不得自动写音乐或更换原修订/目标。指针预览取消不提交，进行中阻止退出。
