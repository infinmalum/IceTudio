## 表单与精度

支持添加、编辑、删除任意受支持 tick 的变化点。位置为工程绝对整数 tick，范围 0–2147483647；不得仅因超出当前片段而丢弃变化点。同一表不允许重复 tick，提交前说明问题；提交时按 tick 排序。速度输入以 BPM 表示，允许小数，转换为四舍五入的整数微秒/四分（1–16777215）；显示实际存储精度及值，未修改的导入速度值须原样保留。拍号范围保持分子 1–255、分母 1/2/4/8/16/32/64/128。tick 和拍号等整数输入不得接受小数，空值或非法范围不得默认为 0 或截断；输入法组合输入与表单按键不能触发音符编辑。

## 小节与时间映射

- 工程 tick 0 是第 1 小节第 1 拍，拍的单位为当前拍号分母（6/8 显示六个八分音符拍，不改用隐含附点分组）。一个四分音符始终对应工程 PPQ；速度变化只改变播放时间，不改变音符/小节横坐标。
- 每个拍号变化点是新小节起点。若发生在旧小节中途，前一小节截短并计为一个小节；不得移动拍号点或音符以强制对齐。同值拍号点也遵守该规则。导入的非小节边界变化保留，界面解释这种编号约定。
- 拍长为 `PPQ*4/分母`，小节长为拍长乘分子。采用 1/32 tick 的整数单位计算：受支持分母均整除 128，且显示窗口的端点放大 32 后必须为 JS 安全整数。时间图点最大 tick 不限制片段末端；尺子会延续最后拍号，在放大坐标不安全时明确提示不能精确显示，不崩溃或自动移动片段。显示允许分数 tick，不对音乐数据进行舍入。小节号通过拍号区段直接计算，不能为跳到很远的片段枚举从头到尾的每个拍。
- 钢琴卷帘尺使用工程绝对 tick；音符仍为片段局部 tick。内部页索引从 0 开始，当前页起点为片段起点加 `页索引*16*PPQ`，界面页码从 1 开始。小节、拍、拍号变化及速度变化在相同四分音符坐标上投影，随横向滚动/缩放同步；不覆盖或重新解释音符的吸附。
- 尺子只生成当前页的刻度，缩放范围为每四分音符 16–200px；宿主滑条、上游缩放滑条与 Ctrl+滚轮均须同步。手势期间阻止 Ctrl+滚轮缩放，缩放后保持宿主吸附选项。普通刻度按 12px 桶限制数量，标签另按可读间隔抽稀；速度/拍号变化分别按 16px 桶分组，显示数量与范围，全部变化点仍可在表单查看。最多 16 个四分音符的页面生成少于 1024 个刻度组，明确提示抽稀/合并，不因极小拍长而无限挂载 DOM。缩放、翻页和看尺不提交音乐事务。

变化点表单每张图每页 24 行；分页只改变投影，应用时仍校验并提交全部草稿。输入为空、重复或越界时在应用内显示原因。保存结果不明时保留草稿，并在模态内提供原操作查询；查询后可以对照工程重新载入或关闭，不自动以新操作重放草稿。
