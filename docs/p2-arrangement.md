# P2 编排画布增量契约

状态：2026-10-18，当前增量的实现与验收契约；本批代码与浏览器/服务验证已完成，具体范围见末节。接续 [P2 编辑设计](p2-midi-editor.md)，不代表 P2 整体验收。

## 操作边界

- REPLACE：ProjectEditor 的轨道/片段列表展示替换为多轨时间轴；轨道选择、静音/独奏、片段选择仍可用。全部片段另可通过所选轨道的下拉框访问，并用“显示选中片段”定位，不因分页失去入口。
- ADD：片段本体水平拖动、真实右边界拉伸、分页/缩放/吸附、重叠片段分行、手势取消和退出阻拦。
- KEEP：轨道/片段新增、重命名、删除、精确数字编辑；钢琴卷帘、播放、工程事务/历史、控制/原始事件、CLI/API、Agent/权限/扩展和所有内部执行机制。无 schema、公共服务契约、依赖或兼容层改动。
- 本批不实现跨轨拖动、多片段整组选择/复制、片段循环、左边界裁切或滚动自动跨页拖动。这些不是已有入口的删除；后续能力须另定语义。

## 时间轴与显示

横坐标为工程绝对 tick，每页 16 个四分音符，独立于钢琴卷帘分页。默认 64px/四分音符，缩放范围 16–200；使用已有变拍小节尺。页面涵盖所有片段的末端，至少一页；“显示选中片段”跳到片段起点所在页。视图操作不写工程历史。

每页显示与半开区间 [pageStart,pageEnd) 相交的片段，包括前页开始的持续片段。显示裁切边界，不产生副本；开始手势时只在真实右端位于本页且可命中时提供拉伸柄；正在拉伸时保留已捕获的柄，以便右端离开页面后仍可完成或取消本次手势。重叠片段以起点、末端、ID 排序后放到首个空闲子行，不互相遮挡；子行分配仅用于当前页显示。不限制子行数量来隐藏片段，密集同页仍可能昂贵，不宣称已达性能预算。轨道名与 M/S 固定在横向滚动左侧。

片段过短时保留可见标记，精确操作可用下拉框和既有起点/长度表单。页面末端恰好结束的片段不在下一页出现。页面计数使用片段末端（起点、长度各自上限 2147483647 tick），不把总末端错误限制为单字段上限。

## 手势、提交与取消

主指针按下冻结工程 ID、修订、轨道/片段 ID、原起点/长度、PPQ、缩放和吸附。移动只改起点，拉伸只改长度，局部音符/控制/原始事件保持原值。吸附选择为四分音符的 1/4、1/2、1、2、4，默认 1；将像素位移除以冻结缩放，按吸附步长取最近整数（负半步远离零），再将取整后的步数乘吸附步长和 PPQ，对绝对值四舍五入并恢复符号，得到整数 tick 位移。原片段不在网格上时保留其偏移，不把按下本身变成量化。

松开提交一个 `clip.update`，使用原基础修订；未产生 tick 变化不提交。负起点、非法长度、单字段越界在预览提示并拒绝提交，不夹取、不截断事件。收短后的事件容纳检查由既有权威服务决定，失败整组零变化。外部更新不替换活动手势的基准/预览；松开仍用原修订，冲突后刷新并提示，不重算、不重放。

Escape、pointercancel、窗口失焦、页面隐藏、选择切换、工程卸载取消预览并清理捕获/监听，不提交。拖动期间禁用分页/缩放/吸附；保存/结果未知或退出检查冻结期间不能启动手势。按已有退出契约注册活动片段手势，关闭请求阻止本次退出，用户完成或取消后可重试。

键盘 Enter/Space 选择片段；精确移动/长度和撤销入口沿用原有表单/工程工具栏，本批不截获输入法或新增全局音乐快捷键。画布不拥有第二份工程状态或撤销栈。
