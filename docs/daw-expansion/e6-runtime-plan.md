# E6 Linux 运行接线计划

本文规定 E6 运行接线的实施顺序。验收范围以 E6 实施计划和 A08/A12 为准。

1. ADD 每个音频实例的隔离助手和固定共享缓冲。只从显式扫描的本机登记项解析代码，核对摘要。实例只接收自身状态和音频数据。实时宿主按序读结果且不等待。离线宿主在有界期限内等待，错误通过现有原子导出路径返回。
2. ADD 混音槽和轨道乐器的可携带身份、参数和状态。使用现有 `mixer.set` 事务，确保删除轨道、撤销和重开均处理实例。保留缺失的身份和数据。用固定输入和样本验证两种 ABI 的乐器、效果、延迟和故障降级。
3. ADD Native 参数、预设、恢复和音色入口。第三方窗口的显示权限单独处理。冻结使用工程资源与可撤销编辑。节点组合通过同一有向图和延迟计算，不能通过 Agent 任务图执行。
4. KEEP 内置合成、采样、混音、可携带工程、IPC 与 Agent 边界。无 DELETE 或 REPLACE。AU 归 E8。单元和隔离夹具的结果不能替代物理设备、真实窗口和厂商矩阵验收。
