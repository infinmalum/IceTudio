# E5 本地素材、采样器与音频精修

2026-11-07。Linux 编码已完成。实施范围为 Linux Native 工作区和现有工程服务。

1. ADD 本地素材索引。只扫描用户选择的普通 WAV/FLAC，限定数量、大小和解码帧数。记录来源路径、标签、收藏及可修改的 BPM/调性。分析推断和人工值分别标示。预听使用独立、可取消的本地音频流。
2. ADD 复制和本地引用放置。复制保留已验证的规范 PCM。引用在本机独立登记绝对路径，工程只持有内容标识。读取时重新校验解码哈希。缺失允许用户定位并验证同一内容。便携包嵌入已验证内容，不携带本机路径。
3. ADD 轨道采样器。区域按音高/力度映射、根音、源帧窗口和包络触发。采样器和 MIDI 控制数据共享轨道事务；音符在快照中调度为有界 PCM 声部并进入该轨混音。鼓垫采用单次触发区域，能预听和输入现有步进器。
4. ADD 波形自动切片与音高校正。精修作业读取冻结修订的源窗口，派生新内容并保留原资产、参数和哈希。采用已安装 FFmpeg 的 Rubber Band 进程滤镜。固定单声部校正和手动移调的适用范围明确，处理支持取消，应用前可预听。切片仍共享原源文件。
5. ADD take/comp。原录音日志保留，可重复预听和选段；对同一工程提交多个选段时校验修订、位置和重叠边界，使用共享撤销。循环选段按冻结窗口换算帧数，实际设备延迟另行测量。
6. KEEP E3/E4 回放、资源包、录音恢复与 E2 MIDI 交换。保留 Agent 原权限和执行框架。DELETE 无。

验证覆盖合成测试素材的分析、复制/引用/重定位、派生时长与基频、采样根音与力度、补偿后渲染、take 选段与撤销、便携包重新导入。音乐质量和实体录制验收独立记录。

## 工作区入口

| 入口 | 行为 |
| --- | --- |
| 工程浏览器 → 本地素材 | 索引所选目录中的 WAV/FLAC。按名称、标签、调性、BPM 和收藏筛选。切换素材停止旧预听。推断的速度和调性分别标记，分析保留已有手填值。 |
| 素材 → 编排或采样轨 | 拖到编排轨道时按当前网格放置，也可点「放入编排」。默认复制为规范 PCM，可勾选「引用原文件」。「建采样轨」同时建立源资产、采样器和可编辑 MIDI 片段。 |
| 工程浏览器 → 定位音频引用 | 选择新路径后比对规范解码的哈希和帧数。完整 PCM 副本优先，资源包内无本机路径。 |
| 工程浏览器 → 采样器 / 鼓垫 | 编辑根音、键区、力度区、源窗口、ADSR 和增益。鼓垫覆盖 MIDI 36–51，可试听已有映射。E2 步进器可加载已映射的鼓垫。 |
| 编排 → 音频片段 → 切片 / 拉伸 / 校正 | 瞬态切片共享原资产，将检测帧换算为最近的工程 tick。拉伸和校正先生成可试听候选，应用后才更新片段引用。 |
| 录音 → 音频 Take Comp | 从已停止的 take 按帧截取并预听选段。按目标音乐位置整组提交，拒绝组内重叠。按循环的固定帧长选择录音轮次。已使用的原 take 随资源包保存，副本可重新选段。 |

采样器最多每轨 32 个区域、工程同时 128 个采样声部。重叠区域可叠加。未映射音符不发声。音符门控和单次触发采用线性插值变调，实时与导出经过 E4 轨道图。原 MIDI 控制事件保留供编辑和交换，采样器当前使用音高、力度、包络和增益。

素材预听最长 20 秒。BPM 来自起音间隔，调性来自有声音高的分布，证据不足会留空。自动校正估计稳定单声部的基频，并对整个源窗口做一次修正，适合单音采样和稳定持续音。手动移调支持 ±12 半音，独立拉伸范围 50–200%。候选处理当前源窗口及反向状态，保留原文件及派生参数。逐音符人声修音和多声部音高校正超出当前入口。

循环拆轮使用冻结的速度图和录音采样帧，保留最后一轮的完整已写帧。设备与传输的物理起点对齐及漂移补偿继续按 A07 验收。撤销 Comp 会移除本次工程编辑，录音日志仍可选用。

精修调用已安装 FFmpeg 的 Rubber Band 滤镜。预听使用本机 PipeWire 命令行工具。Rubber Band 提供 GPL v2 或更新版授权以及商业授权选项。本次没有打包这些工具或素材。[FFmpeg 滤镜文档](https://ffmpeg.org/ffmpeg-filters.html#rubberband) · [Rubber Band 许可](https://breakfastquay.com/rubberband/license.html)

- 实体录音对齐、设备异常、真实输入手势完整走查及 A14 音质人工试听仍待验收。
