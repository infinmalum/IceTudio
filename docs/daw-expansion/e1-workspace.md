# E1 工作区与连续编辑：执行契约

日期：2026-11-05。状态：代码与自动化闭环完成，物理设备/人工验收待完成，见 [交付记录](e1-acceptance.md)。维护者已明确恢复编辑器路线，要求按完整阶段推进。本文件细化 implementation.md 的 E1，不取消 A04/A15 的设备验收门槛；MyGo 设备/跨平台缺口仍保留。代码基线 67f6974，开始时工作区干净。

## 顺序与范围

1. 核对 MyGo 工作区、Arrangement、卷帘 hook/projection/adapter、Native 工具协议、时间图、偏好及真实窗口探针。复用既有服务与测试，记录布局/视口基线。
2. 工作区提供浏览器/助手显隐、编排/拆分/卷帘视图与重置；窄窗口自动收起侧栏以保护画布，显式偏好单独持久化，布局变化不写音乐。
3. 统一音乐吸附标签：关闭、1/4、1/8、1/16、1/32、1/8T、1/16T、自适应；Alt 临时关闭。按整数 tick 舍入，PPQ 小时最少一步一个 tick。位置采用小节/拍/拍内 tick，必须精确可逆；高级 tick 入口保留。
4. REPLACE 用户可见的编排/卷帘翻页按钮与页码为连续滚动/定位；KEEP 原 vendor 引擎、完整选区 ID、CC/raw、原版/候选 ghost、精确编辑与草稿。底层可使用有界渲染窗口，远端通过位置跳转进入，不分割工程状态。
5. 增加播放头与关闭/页跟随/连续跟随；手动导航暂停跟随，显式恢复。只接原 Go 播放状态与 seek/loop 服务，不启用浏览器音频。
6. 建立可发现的快捷键/上下文入口、复制/粘贴与 Escape 取消。输入框、IME、对话和模态中不劫持音乐键。手势冻结修订/对象；滚动、外部更新不能偷偷 rebase；一次松开最多一组事务。
7. 验证并回写矩阵：Go/TS 规则、真实 SQLite 事务与恢复、Native 控件、实际 MyGo/WebKit。包含 1k/10k 密集与分散负载、长音、视口外选择、复制/粘贴、外部冲突/取消、ghost、布局与键盘。记录计时对象/样本，不能把总探针时间当输入 p95。

## 退出标准与不可自动豁免项

代码/自动化交付必须覆盖上述 1–7 的可执行部分，提供真实窗口记录与恢复检查；不能用几项按钮修改作为整节完成。物理 IME、200% 系统 DPI、多设备声音/延迟、屏幕阅读器和维护者任务走查需要相应设备/人工证据，未实际完成就标记待验收，不能宣称 E1 全部验收通过或直接恢复 Agent 内核重构。

## 密集重合音符的绘制决定

实测 10k 密集样本含大量位置/时长/音高/力度/通道完全一致的叠层，逐层 DOM 不增加可见信息却使滚动超出 A04 目标。本节将完全相同且选中状态一致的可见 glyph 合并绘制，显示层数；不同选中状态分别绘制。工程、查询、框选、全选、变换、复制、撤销仍保留全部稳定 ID；普通点击编辑当前可见代表，删除/移动后下一层重新显现。不是合并音乐或去重写入，不改变 MIDI 导出事件。测试必须核对分组不修改源数组、混合选择状态可区分及 10k 全选/变换/撤销仍覆盖全部 ID。
