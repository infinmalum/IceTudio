## 覆盖范围

从两页 HTML 的 img src、各 srcset 最大尺寸候选及 video poster 提取，按 URL 去重，共 171 个栅格图片地址，成功下载并校验 170 个。为避免遗漏界面裁切，保留了 PNG/JPEG/WebP 的部分重复版本，同时包含人物、标志和营销辅助图；数量不能解读为独立软件截图数量。

未成功：bt.32ba7ee.webp。本次唯一失败为人物宣传图，重试后仍网络超时。视频本体、无封面视频的画面、SVG 图标、CSS 背景和动态交互后才加载的素材未提取；不能宣称这是网站所有媒体的完整镜像。视频地址另列在 manifest 中。

已用图像解码器检查成功图片可读，并核对文件哈希；已查看全局/编排/卷帘/混音等参考缩略图。画廊直接读取本地文件，不依赖在线加载。
