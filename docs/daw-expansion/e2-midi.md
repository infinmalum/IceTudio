# E2 MIDI 创作实现与验收记录

日期 2026-11-07。本文面向维护者和编辑器实现者，细化 [DAW 实施计划的 E2](implementation.md)。E2 的功能代码已接入。物理输入和设备试听继续按 [验收矩阵](acceptance.md) 单独验收。

## 编辑器入口

| 入口 | 可执行操作 |
| --- | --- |
| 编排 | Ctrl/Cmd 点击扩展选择，Shift 拖动框选。拖动选区或分组可整体移动。批量面板支持跨轨、独立复制、重复铺排、拆分、合并、裁剪、分组和解除分组。 |
| Pattern | 用「保存到 Pattern 库」保存选中片段，或用「共享铺排」保存并创建链接实例。从浏览器拖到编排轨道，或在「Pattern 库」指定轨道、位置和次数。链接片段可以解除关联。 |
| 鼓组 | 可同时编写 8 行 GM 鼓音色，每行设力度、静音和独奏。每个循环 1–32 步，每四分音符 1–16 步，支持摆动、概率、重复、整段试听和显式替换对应鼓音高的现有音符。将成品片段保存到 Pattern 库即可重复放置。 |
| 卷帘 | 大调和自然小调可按任意根音高亮。控制通道随卷帘滚动，显示力度、CC 或弯音，可画点或直线、选择区间、调整值及删除控制点。力度通道改变现有音符力度。 |
| 和弦 | 选择大调或自然小调，使用候选级数或输入 1–32 个罗马数字，生成每四分音符一组三和弦或贝斯根音。可以先试听草稿。锁定后重生成与声部连接见 E7。 |
| 段落 | 片段内的标准 SMF 段落标记随片段移动，显示在编排标尺，并随标准 MIDI 导出。 |
| 传输 | 「节拍器」随工程拍号、速度和循环播放。「预备拍」按目标位置的拍号和速度播放一小节，播放头保持在目标位置，随后进入工程。控件在下一次播放时生效。 |

音符和控制点通过共享事务提交。原生表单保存草稿，应用时检查打开表单时冻结的工程和修订。卷帘控制点在松开指针时提交，取消手势不写入。编排位置支持整数 tick 或小节:拍:拍内 tick。鼓组概率在生成时确定落点。试听、持久化、重做和导出都使用同一组生成规则和实际事件。

## 事务与读写边界

| 命令 | 载荷和约束 |
| --- | --- |
| `clip.arrange` | `arrangement` 指定 `action`、`ids`、绝对 `tick`。移动、独立复制和共享铺排可指定目的 `track`。复制按所选片段覆盖的时间跨度重复。单次最多选择 64 个片段，最多产生 256 个片段。 |
| `clip.arrange` 拆分、裁剪、合并 | 拆分点在片段内部。裁剪用半开区间 `tick` 至 `end`。拆分跨界音符保留左侧 ID 并分配右侧 ID，控制与原始事件按区间分配。合并限同轨，保留最早片段 ID 和现有事件绝对位置。 |
| `clip.arrange` 分组和 Pattern | `group`、`ungroup` 管理编排分组。 `makePattern` 保存一个独立片段并建立首个关联。 `link` 共享铺排，`detach` 解除指定实例。 |
| `pattern.place` / `pattern.remove` | `patternId` 指定资源。放置带目标轨、绝对 tick、1–64 次重复。每个资源最多 256 个实例。删除只接受无引用资源，可以撤销。 |
| `control.update` | `clipId` 和 1–128 项带原 ID 的 `events`。领域层校验 MIDI 字段、片段范围和身份。控制事件桥接仅接受当前片段的 CC 或弯音。力度沿用音符更新。 |
| `marker.add` / `marker.remove` | 新增带片段内 tick 的标准 SMF 标记，名称最多 127 UTF-8 字节。删除使用单个标记 ID 并校验事件类型。 |

Pattern 资源保存内容值，实例保存独立的稳定片段/事件 ID、轨道、绝对起点、名称及颜色。任一实例的音符、控制、标记和长度修改在一个事务里同步到资源及所有实例。读取、播放、分页、差异和 SMF 导出使用物化实例。资源即使没有实例也可以重新放置。常规复制创建独立片段。拆分、合并和裁剪共享实例前先解除关联。标准 MIDI 导入得到独立片段。

Agent 冻结范围必须覆盖所有受影响的共享实例。跨轨命令还检查源和目标轨。放置或删除既有资源要求整工程权限。按轨、片段或区间读取时，查询返回获准的片段内容，资源库全集只出现在整工程读取。重做沿用已分配身份。数据层、CLI/IPC 和 Agent 沿用同一事务服务。试听在独立音频快照中运行，修订变化会使试听过时。

节拍器点击是播放事件，以采样帧调度。预备拍由同一音频回调执行。停止、定位和重建播放快照时清除当前点击，循环继续按工程拍号定位。标准 MIDI 导出仍使用工程事件。

## 验证范围

- 领域和持久化回归覆盖跨轨、拆分、合并、裁剪、共享 Pattern 的事件身份、撤销重做、删光实例后重新放置和权限边界。Native 控件测试验证拖动分组只提交一次。
- 实际 Linux MyGo/WebKit 回归使用临时工程。通过表单生成 8 小节鼓、贝斯和和弦，核对拆分撤销，以及 MIDI 导出、重新导入后的 176 个音符、CC 和段落标记。真实卷帘的控制点按钮提交后，两个共享实例同步。
- 原生离线 PCM 核对变拍时的点击位置、预备拍结束时工程播放头、停止后的静音。设备听感、真实鼠标与触控板的拖放和框选、中文 IME、系统 DPI 及人工完整创作走查仍需对应设备证据。
