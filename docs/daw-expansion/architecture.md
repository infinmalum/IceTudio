# DAW 架构扩展与保留边界

状态：目标设计，尚未接入。当前实现以 ../architecture.md 与 P1–P4 契约为准。本文列出新增模型与执行约束；API/schema 的最终字段在相应阶段实现前通过设计评审冻结，不允许开发者自行省略能力。

## 模块和数据职责

| 层 | 现有基础 | 目标增量 |
|---|---|---|
| 工程领域 | internal/project | AudioAsset、AudioClip、Pattern/PatternInstance、AutomationLane、MixerChannel、RoutingEdge、DeviceInstance、Marker、Take/Comp；对象稳定 ID，序列化版本与资源上限 |
| 命令服务 | internal/app 工程服务 | 对新对象增加 query/select/edit/diff/inverse，GUI、CLI/IPC、Agent 同路；整个意图原子提交 |
| 持久化 | internal/storage + SQLite | 版本化工程与资源引用；插件状态 blob 与资源哈希；工程历史保护仍被引用资源 |
| 播放 | internal/playback + FluidSynth | 音频图、轨道独立输出、效果/路由、自动化调度、实时录制、统一离线渲染；旧 MIDI 路线在等价验收前保留 |
| 资产 | 新专用资产服务 | 哈希、元信息、许可/来源、缓存与引用计数、波形摘要、缺失定位；不存于聊天历史 |
| 插件 | 新隔离宿主进程 | 扫描与运行隔离、状态/参数/延迟、崩溃恢复、平台窗口嵌入；实时线程不调用模型 |
| 界面 | React/Wails + GridSound 适配 | 连续视口、鼓组、波形、Mixer、素材浏览；可替换渲染层但不能另造权威工程 |
| Agent | 五角色与冻结范围 | 新音乐对象语义工具、差异与试听；权限覆盖资源/设备/导出/外发，保留审查与恢复 |

## 时间与编辑语义

音乐时间维持整数 tick + PPQ + tempo/meter map。音频源定位使用整数采样帧，源采样率不可因工程采样率变化丢失；片段播放窗口以音乐时间或绝对时间锚定，锚定方式为显式属性。变速时只移动音乐锚定对象；绝对锚定保留物理时间。舍入规则、插值和边界误差须在 E3 前形成样例与测试。

Pattern 保存共享事件，instance 保存起点/长度/循环与局部参数；编辑共享 pattern 会展示受影响实例，提供“独立副本”。旧 Clip 不能未经确认转换成共享实例。拆分/crop 不删除源数据；历史仍引用的资产不能被清理。录音使用临时写入与独立恢复日志，完成后验证哈希并提交资产引用；崩溃留下可恢复 take，绝不把半写文件当完整资产。

自动化采用稳定 target ID + 参数 ID，值域/单位/插值/默认值显式声明；MIDI CC 与音频参数不是同一类型。删除目标要列出受影响曲线，整组撤销能恢复关系。自动化读取/触碰/锁定模式的接管与释放时点先定契约，禁止 UI 和引擎分别解释。

## 实时与离线引擎

UI/数据库/模型在音频回调外构建不可变快照，音频线程只读取已发布图及有界事件队列；禁止文件 I/O、无界分配、网络、数据库与阻塞锁。切图采用代际标识和明确生效边界，过时编译结果不能重新启动已停止的播放。

当前 FluidSynth 多实例路由不能自动当成独立音频轨混音。E4 必须实测逐轨输出策略与 CPU/内存，再决定复用多输出、独立 synth 或替换后端；未证明等价前 KEEP 原播放路线。图初期拒绝反馈环，侧链是显式边；Patcher 阶段支持何种延迟反馈必须另行冻结。延迟补偿按图累计插件延迟，动态变化重建快照。

离线渲染复用同一图、调度和参数解释；尾音、区间前追溯、随机种子和插件实时专用模式显式处理。录音输入补偿与输出监听延迟分别记录，设备断连停止受影响录制并保留已写数据。停止/seek/loop 释放持续音、踏板与效果状态，策略可测且不能把爆音当可接受副作用。

## 资源、导出与插件

本地资源复制/引用由用户选择；可携带工程导出清单列出资源、哈希、许可限制和缺失项，密钥/聊天不包含。导出写同目录临时文件，校验成功后原子发布；取消清理本次临时文件，不删除旧成品。资源清理必须枚举工程、历史、草稿、候选、录音恢复引用，未知引用默认保留。

插件扫描在独立进程，超时/崩溃可隔离；保存 manufacturer/plugin ID、格式、版本、参数/opaque state。缺失插件保留状态与链位置，提供定位/旁通/冻结音频；不得静默移除。插件状态变化同样经事务记录，插件自身窗口动作需桥接宿主自动化/撤销边界。

VST3/CLAP/AU 的 SDK、许可证、平台支持及二进制分发在选型阶段验证，不从品牌名称推断许可。安装依赖和模型权重需遵守用户下载许可规则。项目不加入 FL 商标/图标、专有插件实现或官网截图到发行包。

## AI 音频与云端

分轨/音高校正/素材生成是可取消的后台作业，使用冻结源资产和参数版本；输出进入候选资产，试听通过后原子加入工程。原始资产保留；模型版本、权重许可、输入输出哈希和本地/远端目的地可查。没有音频理解或实际试听证据时不能宣称音乐质量提高。

云备份是显式功能，首次上传展示范围和目的地；备份清单与内容校验一致发布，失败可续传，不覆盖唯一完整备份。恢复先生成独立副本，校验资源后用户选择切换。服务/账号/加密密钥管理方案在 E8 之前决策；未选服务不伪造实现。
