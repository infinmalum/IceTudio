# 验收矩阵与发布门槛

状态：验收要求，不表示已经通过。2026-11-05 的 E1 自动化与剩余 A04/A15 门槛见 [E1 交付记录](e1-acceptance.md)；下表不因局部通过而整体改为已验收。执行者记录日期、代码修订、设备/系统、素材/插件版本、命令、结果及证据路径。性能数值是初始目标，E0 用基线确认；若无法达到须记录原因与明确范围，不能事后悄悄放宽。

| 编号 | 场景 / 方法 | 通过标准 |
|---|---|---|
| A01 离线创作 | 禁用模型与网络，新建鼓/贝斯/和弦/旋律，编辑、试听、保存重开、MIDI/音频导出 | 原生窗口完成；工程与声音保存，不依赖 Agent |
| A02 编辑一致性 | GUI、CLI/IPC、main/worker 对同一批对象操作 | 同一事务语义；过时修订拒绝；重复 opID 不重复提交；撤销/重做身份与顺序一致 |
| A03 MIDI 保真 | CC/踏板/弯音/程序/触后/meta/raw，变拍变速与长音 | 受支持事件往返符合当前 SMF 契约；拒绝不支持格式且保留文件 |
| A04 视口与键盘 | 1k/10k 分散与密集音符、连续滚动、框选、跨视口拖动、IME | 记录 p50/p95 输入到反馈；目标可见操作 p95 <100ms，提交到稳定显示 <500ms；无焦点丢失/偷偷 rebase |
| A05 多片段/pattern | 跨轨复制/拆分/合并/循环、共享/独立实例 | 一次意图一次撤销；权限不足整组失败；源事件不被裁切误删 |
| A06 播放 | stop/seek/loop、双踏板、长尾音、播放中编辑/删除、候选切换 | 无遗留持续音或旧调度复活；PCM 与设备结果分别记录 |
| A07 音频时序 | 实体回环、不同 buffer/采样率、长录制漂移 | 记录往返延迟/抖动/补偿误差；目标监听往返 ≤20ms、校准后定位误差 ≤5ms；不支持的设备明确说明 |
| A08 混音 | 脉冲对齐、路由/侧链、自动化边界、插件延迟变化 | 测试信号符合图规则；离线与实时差异可解释；非法图拒绝 |
| A09 实时负载 | 48kHz/256-frame 基准，64 MIDI 轨、20 音频轨，另列效果链 | 连续 30 分钟无可归因于应用的 xrun；记录 callback p99 和 CPU；目标 callback p99 <周期的70%；硬件配置必须随报告 |
| A10 录音恢复 | 录制中磁盘满/断连/SIGKILL，重开 | 已写 take 可识别与恢复；不宣称断电验证；不覆盖现有作品 |
| A11 导出 | WAV/FLAC、区间、分轨、尾音、取消/失败、重复文件名 | 外部解码可读、时长与对齐正确；发布原子；失败不覆盖旧成品；保留许可说明 |
| A12 插件 | 扫描崩溃、运行崩溃、缺失/版本变化、状态重开、离线渲染 | 宿主/工程可恢复；插件状态不丢；独立格式与平台分别通过 |
| A13 Agent | 真实模型局部编辑，新旧选区、并发手改、拒绝、取消、未知结果 | 冻结目标不变；不能越权；原版/候选可区分；未知只核对不盲重放 |
| A14 音乐质量 | 和弦/loop/stem 各类代表性素材，盲听或 A/B，至少两轮修改 | 记录音质、节奏、和声、分离伪影和失败样例；无评审记录不得宣称效果提升 |
| A15 UI | 规定窗口/缩放、深浅主题、键盘、屏幕阅读标签、焦点 | 核心操作可达，无关键控件遮挡；颜色外另有状态标识；实际完成 UI 规范流程 |
| A16 资源与云 | 源文件移动、资源缺失、云断网、冲突、恢复到新位置 | 不静默替换/删除，校验清单一致；凭据/聊天不混入；恢复副本可打开 |
| A17 发布 | Linux/Windows/macOS 干净安装各自测试 | 安装依赖和音色齐备；第三方通知完整；无官网参考图进入二进制包 |

自动化层：领域/存储单测→服务/IPC 集成→真实工程浏览器→实际 MyGo/WebKit→真实设备/插件/模型→音乐效果评审。上层门槛不能由下层替代。文档和 UI 截图不计运行验收。

交付记录模板：需求 ID、实现路径、前置条件、步骤、预期、实际、证据、通过/失败/阻塞、已知限制、复验触发条件。每个 F 项需链接相应 A 项和实际报告；全部有关项通过才改为已交付。
