## 1. 布局与尺寸

基准窗口 1440×900 CSS px，另验收 1280×800、1920×1080 和 200% 系统缩放。基础间距 4/8/12/16px；正文 13–14px、辅助信息最低 12px，按钮常规高度 28–32px，重要触控入口至少 36px。数字时间使用等宽数字。

```text
┌工程菜单/名称/保存状态────────播放 停止 录制│BPM 拍号 循环│布局┐
├浏览器 220──┬上下文工具条：选择/绘制/切割/吸附/量化─────┬Agent 320┤
│工程/音色   │小节尺 + 段落 + 循环区域                  │目标范围 │
│采样/插件   │轨道头 │ Playlist 编排                    │对话/提案│
│搜索与标签  │       │                                   │审批/恢复│
│预听与信息  ├────────可拖动分隔线──────────────────────┤         │
│            │ Piano Roll / 鼓组 / 波形 / Mixer          │         │
├────────────┴状态：选区/提示/音频异常──────────────────┴─────────┤
```

顶栏目标 48px，上下文工具栏 32px，底部状态栏 24px。浏览器 180–320px；Agent 280–420px；中央至少 640px，不足时先折叠浏览器，再将 Agent 改抽屉，不把编辑画布压成不可用细条。左右面板可隐藏；中央下部面板默认占中央高度 40%，可在 25%–75% 调节。布局状态与音乐工程历史分离。脱离显示器后窗口自动回到可见区域。

预设：编曲（编排+卷帘）、节拍（编排+鼓组）、混音（编排+Mixer）、Agent 审阅（编排+差异）。未实现面板不得显示假控件；新增布局不能移除任务详情入口。

历史实现核查项（2026-11-01）：旧 ProjectEditor 的 data-view/CSS 选择器不一致已在当时修复；该普通 React 载体现已退役。当前布局采用 MyGo Native，连续编辑的实现与实际窗口验证见 [E1 交付记录](e1-acceptance.md)。

## 2. 视觉系统

Native 工作区的底色、面板与焦点色在暗色使用 `#1A1E24`、`#272C34`、`#83C0ED`，在亮色使用 `#F8FAFC`、`#EEF2F7`、`#215F94`。常规控件圆角 7 DIP，创作区域边界保持清楚。正常文字对比度目标至少 4.5:1，大字及识别控件状态所需的轮廓至少 3:1。亮暗主题使用一致的信息层级。

把功能层与内容层分开。顶栏、侧栏及浮层使用中性表面、细分隔与有节奏的留白。顶栏用分段控件切换布局，播放、暂停、停止保持同组。轨道、网格、音符和波形使用稳定的不透明背景，轨道颜色只在有音乐语义的位置出现。当前跨平台基线使用不透明面板。后续半透明实验仅限工具栏或临时浮层，并须验证低对比环境、较低性能设备和关闭透明后的表现。[Apple 的材质指南](https://developer.apple.com/design/human-interface-guidelines/materials) · [Apple 的工具栏指南](https://developer.apple.com/design/human-interface-guidelines/toolbars)

颜色职责：轨道色标识对象；蓝色表示选择/焦点；新增用绿色+“新增”形状标签，删除用红色+删除线；录音红色仅在真实录音状态使用。禁用态必须给出原因和可执行下一步。不能只用红绿表达差异。

小节线 > 拍线 > 细分线分三级对比；黑键行轻微加深；音符主体保持清楚边界。播放头、当前编辑选区、Agent 冻结范围分别使用实线、填充边框、虚线阴影，附图例。播放头位置来自原生时钟，UI 插值只用于显示。

## 3. 连续时间轴与手势

取消用户可见的强制分页，保留底层按视口加载。横向连续滚动，缩放锚点保持鼠标下音乐时间；双击标尺定位，拖动标尺建立循环，拖动边缘微调。播放跟随提供关闭/页跟随/连续跟随三态；用户手动滚动时暂停跟随，显式按钮恢复。

跨视口持续音和片段都可直接选中；离屏对象通过稳定 ID 保持选择。Shift 扩选，框选必须说明选中还是相交；初版规定相交即选中。Esc 取消当前手势，松开只提交一次事务。后台更新不能改变手势起始修订。

默认位置输入小节:拍:细分，显示与转换共用 tempo/meter map；高级面板可切 tick。时间图中途变拍沿用当前截短小节语义。吸附为关闭、1/4、1/8、1/16、1/32、三连音及自适应；Alt 临时关闭吸附。样本编辑区另提供采样帧精度，不混用单位。

片段支持跨轨拖动、Alt 拖动复制、边缘裁切、循环扩展、拆分、合并和多选批次。裁切只改变播放窗口、不删除源事件；拉伸是独立工具，不能让同一手势隐式改变音符时长。MIDI 合并需校验通道/顺序/重叠；音频合并先保留非破坏性组合。

## 4. 编辑器与混音台

Piano Roll：工具栏只留工具/吸附/量化/音阶；音符精确属性放检查器。下部通道切换力度、踏板、表情、调制、弯音；支持画笔、直线和选区变换。原始 MIDI 事件仍有只读/受支持编辑列表，不能因没有图形控件而丢弃。

鼓组：每行音色、M/S、预听、步进格；每小节分组。概率和 swing 必须可冻结随机种子或导出实际结果；播放与离线导出采用同一解释。pattern 是音乐资产，不复活旧通用场景模板。

Mixer：轨道条固定名称/颜色、输入/输出、插入效果、电平、推子、声像、M/S。峰值保持可清除，削波有数值及提示。主输出始终可找到。路由高级操作用图形面板；不要求输入运行时 ID。选中轨道和 Mixer 通道双向联动，但不能改变已冻结的 Agent 任务目标。

波形编辑器：源文件与播放区域分开标记；裁切/淡变/拉伸/音高校正均可撤销，原版可比较。录音时显示真实输入电平、监听状态、已录时长与写盘故障。

## 5. 浏览器、Agent 与恢复

浏览器按工程、乐器预设、采样/循环、插件、收藏分类；搜索支持类型/调性/BPM/标签。底部固定预听开关和音量；切换素材停止旧预听。外部下载明确来源、大小和授权，缺文件提供定位/重新关联，不静默替换。

Agent 卡片固定显示“作用于：轨道/片段/区间”，发送后改成冻结状态。候选摘要展示改了什么、受影响数量、原版/候选试听、采用/丢弃；逐字段与工具日志在详情。已提交、拒绝、过时、取消、结果未知分别显示。未知仅查询原提交，不出现无条件“重试编辑”。任务图、预算、review/rework/retrospective 均留在任务详情。

工程已保存、输入草稿已保留、待确认提交是三种独立状态。恢复通知合并为紧凑条，展开逐项操作；不能因收纳而解除阻断条件。错误说明对象、后果及下一步，技术栈信息放详情。

## 6. 键盘与验收

Space 播放/暂停、Home 回开头、Ctrl/Cmd Z 撤销、Shift Ctrl/Cmd Z 重做、Ctrl/Cmd C/V 复制粘贴、Delete 删除、Esc 取消；输入框和 IME composition 中不劫持音乐快捷键。工具快捷键可配置，冲突可检测；所有鼠标核心操作须有菜单/键盘等价入口。

布局验收以实际工作流计：新建工程→鼓点→旋律→编排→Agent 局部修改→A/B→撤销→导出。1440×900 下播放、选区和当前编辑内容无需滚动整个页面即可找到；长列表只在各自区域滚动，弹窗焦点闭环，关闭后回到触发控件。舒服程度用真实任务走查、误触/操作次数和维护者试听记录判断，不能仅凭像素截图宣称达成。

## 7. 官网图片的具体使用方式

参考目录中 `fl-studio-screen-demo-poster*` 用于观察全局信息密度，`frame-316129451*` 与 `frame-316129365*` 用于观察卷帘和多面板关系，`frame-316129273-1*` 与 `fl-loopstarter-overview*` 用于观察编排和素材的关系。`frame-316129477*` 可观察混音台的通道条、电平与推子。`frame-2316129298*` 展示效果插件的预设与参数面板，可与各乐器及 `fruity-*` 图片一起用于观察参数分组。文件名仅用于定位，设计师须看图核实局部内容。

优先借鉴：稳定顶栏、统一音乐时间轴、轨道颜色贯穿、密集而对齐的控件、可直接操作的音符/片段、折叠的高级参数。IceTudio 采用停靠布局和清晰 Agent 审阅，不照搬大量互相覆盖的浮窗；专业用户仍可在 E8 脱离面板到多显示器。官网图片含裁切、透视和装饰图，不能把其中像素尺寸直接当成桌面控件规格。

Apple 的参考重点是 [macOS 桌面布局](https://developer.apple.com/design/human-interface-guidelines/designing-for-macos)和[可收纳侧栏](https://developer.apple.com/design/human-interface-guidelines/sidebars)。具体界面使用 IceTudio 的停靠工作区、Agent 审阅和自有图标。截图和品牌资源只作研究，实施使用项目控件和有明确授权的资产。

实施顺序先更新 Native 配色、布局切换和播放控制组，再整理混音台和编辑器工具条，最后校准 Native 与卷帘的边框、字体和色彩语义。每批保留现有操作入口、快捷键、可访问名称和工程持久化。后续混音台改版须以有真实多轨和电平的工程检查推子、路由与选中状态，卷帘须检查网格、音符与选区的区分度。窗口截图可核对布局，实际键盘、系统缩放和创作走查分别验收。
