# E3 音频资产、录音和导出

2026-11-07。Linux 基础功能已接入，自动化通过。物理设备验收保持开放，具体覆盖见下文。

实施顺序为资产与事务、播放和导出、输入与恢复、Native 接线和验证。E2 编排、MIDI 和原有播放入口均保留。E3 使用整数 tick 作为片段起点，源窗口使用 48 kHz 整数采样帧。变速重新计算片段起点，窗口采样数保持固定。E4 的路由、效果与 E5 的高级音频处理另行实施。

- ADD 音频资产和音频片段。资产导入从 WAV/FLAC 解码到工程数据目录的 SHA-256 寻址 PCM，项目保存文件名、哈希、帧数和波形概要。原文件保持独立。读到缺失、截断或哈希错误时明确拒绝播放/导出。保留历史引用的资产，删除片段不清理文件。
- ADD 音频片段命令。验证源边界、位置和上限，支持音量、淡入淡出、反向及源窗口。编辑使用当前事务、恢复与撤销。回放计划在音频线程外加载和校验；音频回调只混合内存中的不可变快照。原生离线渲染与实时播放使用同一快照语义。
- ADD 安全导出。先写目标旁的暂存文件，完成后原子发布。失败与取消不覆盖已有文件。WAV/FLAC 可回读，按工程/区间/指定轨渲染。资源包只包含工程数据、清单和哈希资产，恢复前验证路径、资源量和哈希。
- ADD 输入与 take 恢复。Linux 采用 PipeWire 命令行音频输入适配和 ALSA RtMidi 端口。音频采用 48 kHz 双声道流。录制写独立 take 标识及持久采样，停止、超限与断连保留已写完整帧。MIDI 输入使用主机单调时钟记录消息到达时间，提交时按原工程修订的速度图换算。显式更换修订后使用确认时的速度图。重新打开后按原操作 ID 核对录制提交，显式选择恢复位置。物理设备验收独立记录。
- KEEP app.Service、项目权限、剪辑事务、MIDI 保真、Agent 执行内核和已交付历史。现有文件目录不做清理和迁移。单轨编辑不能读取其他轨道的音频文件。涉及原始资源导入、导出与设备访问的 UI 保持本地显式触发。

## 使用与实现范围

| 入口 | 行为 |
| --- | --- |
| 编排工具条的「导入音频」 | 选择 WAV/FLAC，放到当前播放位置。优先使用选中 MIDI 片段所在轨，其次使用首轨，空工程建立音频轨。源文件复制为应用管理的规范 PCM，不依赖源文件继续存在。 |
| 编排波形 | 拖动调整音乐起点，点击进入属性。可精确编辑源帧、长度、增益、淡变和反向，也可拆分或删除。拆分的两个片段共用源文件。修改、提交和撤销均使用工程修订。 |
| 工程浏览器的「导出音频」 | 选择 WAV/FLAC、主混音或指定轨、区间、尾音、16/24 位、44.1/48/96 kHz、抖动及归一化。分轨逐轨导出，保持工程时基。目标文件存在时保留原件。取消时暂存文件由本次导出清理。 |
| 传输栏的「录音」 | 选择轨道、位置及音频/MIDI 输入。音频可启用实时输入监听并查看峰值。停止后从 take 列表提交。重新打开工程后仍可恢复，过时修订需显式确认新位置和修订。 |
| 工程浏览器的「保存／打开资源包」 | `.icezip` 保存工程快照及去重音频，以 SHA-256 检验。导入创建独立工程，编辑历史、对话、凭据和未提交 take 分开保存。 |

音频导入标准化为 48 kHz 双声道 PCM16，单个解码资产和单次导出上限十分钟。更高导出位深不会恢复导入时舍入的精度。混合 MIDI 与 PCM、定位、循环和离线导出都使用同一个播放计划。Linux 需 FluidSynth 2.6+ 和 ALSA 构建依赖。WAV/FLAC 导入、FLAC 编码及变采样率输出需要本机 FFmpeg，录音与监听需要 `pw-record` 和 `pw-play`。设备列表使用 `pw-dump`。本次使用已安装工具。

录音按指定位置放置 take。物理时钟同步、输入补偿、循环 take/comp 和高级音频处理仍按后续门槛执行。MIDI take 保留音符、控制器、程序、弯音及触后，系统消息与 SysEx 当前由标准 MIDI 文件交换承载。磁盘上的 take 和资产不会因撤销或关闭工程自动删除。音频输入超过五秒没有采样时结束录制并保留先前写入内容。Agent 只发现作用范围已有资产时适用的音频操作，外部导入和设备访问保持 Native 显式入口。

## 验证结果

- 全量 Go 测试、vet 和正式构建通过。实际 MyGo/WebKit 读写回归通过。临时工程验证音频导入、属性草稿、反向和裁剪提交、FLAC 重新导入以及资源包副本。既有 E1/E2 真实窗口和本地模型夹具回归也通过。
- 离线 FluidSynth 与 PCM 混音测试核对准确帧数、反向样本、淡入、FLAC 解码及 44.1 kHz WAV 输出。导出取消和同名失败保留原成品。解码检查覆盖截断 WAV、无效 FLAC STREAMINFO 和超限文件。
- 资源包往返验证快照及资产一致，拒绝哈希损坏内容。模拟输入进程在落盘后被强制结束，重开可恢复完整帧。定向测试核对 MIDI 录制跨变速映射、控制事件和 take 幂等恢复。
- A07 的物理回环延迟与长期漂移、A10 的真实设备断连和磁盘满、A11 的外部播放器试听及完整创作人工走查仍待执行。模拟输入、进程强制退出和 FFmpeg 回读各自只覆盖上述自动化场景。
