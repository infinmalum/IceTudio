# 使用 IceTudio 桌面 App

IceTudio 打开后进入**工程工作区**，采用编辑器为主的三栏布局：左栏是工程栏（新建工程、导入 MIDI 和工程列表，显示名称、修订号与 PPQ，可删除），中间只有编辑器（命令条提供导出 MIDI/重命名/撤销/重做，下方是走带、编排与钢琴卷帘；未实现的能力会如实标注），右侧是 Agent 栏——对话列表（搜索、重命名、删除）、管理助手入口、当前助手与模型连接入口，以及把当前对话绑定到当前工程的开关。日常使用只需在右栏连接模型并发消息；不需要配置 Agent、运行 ID 或工作流程。三栏宽度可拖动调整：编辑器两侧各有一条分隔线，拖动改变左栏/右栏宽度，双击分隔线恢复默认宽度，选择会保存在本机、重启后保持（中间编辑器始终保留最小空间）。窗口收窄到 880px 以下时 Agent 栏才会移到编辑器下方，此时对话栏的分隔线隐藏。

## 音乐工程与对话的绑定

- 工程独立于对话保存：删除对话不会影响工程；删除工程会同时解除绑定，对话与消息保留。
- 在右侧 Agent 栏点“绑定当前工程”后，这个对话里的创作助手可以直接查询和编辑该工程（编辑走同一套修订检查与撤销历史，每次改动都可以撤销）。未绑定的对话不会出现工程工具。
- 重命名/撤销/重做是真实编辑：提交整组事务，携带修订号；如果状态已被其他操作更新，会明确拒绝而不是覆盖。

## 本机数据位置

所有应用数据统一放在二进制旁的 `data/`：配置 `config.json`、数据库 `icetudio.db`、密钥 `credentials.json`、日志 `icetudio.log`、Skills 目录、宿主锁/IPC 文件、命令临时目录 `exec-tmp/`。Linux 的页面存储与 WebView 缓存位于 `data/webview/`，Windows 的 WebView2 数据目录也指向这里。使用本项目默认构建位置时即 `bin/data/`。从别的目录启动不会改变数据位置；AppImage 使用安装的 `.AppImage` 文件旁的目录。应用需放在可写位置，无法写入时会明确报错。更换二进制所在目录时，需要一起移动 `data/` 才能继续使用原有数据。

## 第一次使用

1. 点击“连接模型”，选择服务商。本机可用 Ollama / LM Studio；远端填写服务商提供的密钥和模型名称。自定义地址在单独展开项里填写。
2. 点击“保存并连接”，连接成功后返回工程工作区。密钥单独保存在本机，不写入聊天、助手配置或运行日志。
3. 输入问题，按 Enter 发送，Shift+Enter 换行；中文输入法选词时的 Enter 不发送消息。
4. 发送到远端前，会显示实际接收地址和资料类别。只有明确允许后才继续；拒绝会保留输入，不发送内容。自定义代理按真实地址提示，不假装内容仍只交给原服务商。

## 聊天和资料

- 对话在发送第一条消息时才创建：没有选中对话时（比如刚打开应用），直接在输入区发送即可开始新对话，创建进度与失败提示就地显示（失败时保留已输入内容）。在对话内时，输入框工具条上的“新对话”回到待输入状态，不会产生空对话；没有单独的新对话按钮。产品只有一个内置创作助手，没有助手选择器，也不需要先配置再使用。
- 消息按 Markdown 显示，支持标题、列表、表格和代码块；回复和代码可复制。不会执行回复里的原始 HTML；外部 Markdown 图片提供点击查看，避免悄悄加载远端图片。
- 输出在同一聊天滚动区显示。位于底部时跟随输出；向上查看时保留阅读位置，可点“回到最新消息”。较早历史按页加载，普通聊天不展示工具原始消息。
- 可以选择文件、拖拽文件或粘贴图片；图片显示缩略图。历史附件可预览和另存。DOCX 当前保留提取正文，下载为文本，不能还原原始文档版式。
- “选择文件夹”打开系统选择器，再明确确认此对话的访问范围。选择器本身不授予权限，命令与具体文件操作继续检查。文件夹选择用于新任务，不能扩大旧任务已冻结的权限。
- 粘贴网页链接后，开启已有“联网”开关即可请求读取。当前模型不支持联网时，发送会提供“关闭联网并发送”的明确选择；不会把普通聊天锁死或静默忽略联网要求。
- 切换对话时保留各自未发送文字和选中的文件；文字同时保存在当前窗口的会话存储中。附件草稿目前仅保留在该 App 页面运行期间，关闭或重新加载页面后需重新选择文件。
- 对话自动从第一条用户消息命名，可搜索标题、重命名和删除。删除前有确认，运行中或结果未知时不允许直接删除；关联子任务记录一并清理，本机权限与助手配置不删除。包含已采用助手/工作方法建议的对话会保留来源，需先撤销相关建议才能删除；未采用的建议随对话删除。

## 操作确认与恢复

必要操作会说明“读取/写入哪个文件”“执行什么命令”，而非要求理解工具名称。协作任务的待确认操作也汇总到主聊天。

对中断后无法确定的操作，先检查对应文件或服务，再记录实际情况。可以选择“暂不确定”继续保留，ICEPick 不会自动重放可能已生效的操作。结果与核对依据仍保存在原有审计记录中。

固定流程要求补充信息时，在输入区补充后点“继续处理”，沿用原有进度。需要从头开始时会提醒可能重复此前的修改。运行细节、检查与回顾入口位于“任务详情”；运行 ID、预算、指纹和原始记录在其开发者记录内。

## 助手与设置

- “助手”页编辑唯一的内置创作助手：名称、说明、工作说明以及 Skill/MCP 启用配置，可一键恢复默认配置。产品不提供助手库：没有新建、复制或删除助手的入口，配置对象由应用自动创建并按修订记录版本。工具限制、组件、固定阶段和模型覆盖配置统一放在“设置 → 开发者设置”。助手页的“配置模型覆盖与工作流程”跳转到同一入口，两页共用草稿。
- 模型密钥统一在“设置 → 模型连接”管理。上方选择服务商可替换密钥，下方展开“管理已保存的密钥”可删除；开发者设置不再有另一套入口。“检测已保存的连接”不会保存当前表单草稿。
- 权限页进入时刷新已授予的权限；保存偏好只修改本次编辑的字段，避免覆盖聊天中新允许的文件夹。同一字段发生冲突会拒绝覆盖并提示核对。
- 助手编辑草稿在切换页面时保留；存在未保存内容时提示。恢复默认前需要确认。
- AI 可以根据自然语言创建/改进助手或工作方法。证据从实际工作列表选择，不要求复制 Run ID；任务详情也可直接发起“根据这次工作改进助手”。普通候选可通过表单修改，完整 JSON 仍可在开发者设置编辑。
- 候选仍需手动采用，尚不自动评估或自动发布。新增工作方法可以明确选择用于正在编辑的助手，不覆盖共享来源。
- “设置 / 模型连接”完成模型、密钥和连接检测；“权限”管理当前对话的确认策略与授权；“开发者设置”保留精细权限、原始服务与运行配置。普通流程不需要编辑配置文件。
- 错误优先给出解释和可行下一步，原始原因放在可展开的技术详情中。

## 开发验证与限制

`frontend/e2e/product.mjs` 通过真实 React 页面、Chromium 和模拟 Wails 绑定检查工程工作区首页（含未实现能力的诚实标注）、左栏工程管理（新建/导入/选择/删除）、中间编辑器命令条（重命名事务/撤销重做/导出）、右栏 Agent 栏（对话列表/发送即建对话/对话内新对话入口/搜索/管理助手/模型入口/工程绑定）、统一模型接入、草稿、文件选择/拖拽/粘贴预览、Markdown、输入法、联网恢复、具体目的地授权、文件夹确认、子任务审批、助手编辑/恢复默认、创建失败与延迟、对话管理及窄窗口布局。可在 frontend 目录运行 npm 的 test:ui 脚本；需要本机 Chromium，所有测试产物放工作区 .cache。

后端测试检查工程模型与事务（三入口同一性、重放幂等、过时修订拒绝、撤销重做与重启恢复、范围查询）以及实际来源/目标预览不创建任务或自动授权、附件内容读取、分页顺序、对话删除的事务与共享上下文保留、中断/未知结果阻止删除。MIDI 导入导出语义（配对、事件保留、往返、非法格式拒绝）有独立测试；真实模型兼容、系统原生文件弹框的人工验收和干净环境安装仍按 R7 单独跟踪；模拟验证不等同于这些验收已经完成。
