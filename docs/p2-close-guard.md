# P2 原生退出时的音乐编辑保护

状态：2026-10-18 实现前建立的有效增量契约。接续 [P2 时间图](p2-time-map.md)与[实施计划](../IMPLEMENTATION_PLAN.md)；不代表 P2 整体验收。

后续[时间图草稿增量](p2-time-map-drafts.md)替代本文原先针对时间图的“仅内存、退出丢弃”行为：最新检查点未确认时阻止退出，已确认时可保留草稿退出。下文通用未持久草稿的丢弃机制仍保留，原始验证记录只代表其当时实现。

## 范围

ADD：桌面窗口关闭/正常 Quit 的请求握手、前端退出检查注册表、时间图草稿和工程提交状态的接线及测试。KEEP：全部工程存储、事务/撤销、操作 ID 查询、MIDI 编辑、音频、权限及多 Agent 执行机制。不修改数据库、CLI/IPC 或模型工具，不为时间图执行自动提交，不重放工程事务；单值数字字段沿用下文明确的失焦规则。新增的 DesktopService 仅供本机 Wails 界面握手，不授予音乐写入或外发权限。

本批保护对象是未应用的速度/拍号表单，以及 useProjects 管理的进行中工程操作、结果未知的工程事务。钢琴卷帘进行中的手势也阻止退出，须完成或按 Escape 取消；2026-10-18 的[编排画布增量](p2-arrangement.md)将同一规则扩展到片段手势，验证记录见该契约。单值数字字段仍按原来的失焦提交/拒绝规则工作；力度/播放参数等未应用的输入、设置/助手表单和对话输入不在本批完成声明内，继续保留后续保护任务。已提交工程已经持久化，退出不要求另存 MIDI。后续[提交恢复增量](p2-operation-recovery.md)将待确认标记替换为 Go 持久记录；启动恢复读取未完成/失败也阻止退出与新工程操作，须先重试恢复检查。

## 协议与生命周期

单窗口桌面启动时注册原生 WindowClosing hook 与 application.ShouldQuit；二者走同一 gate。前端先订阅退出事件并安装检查，最后调用 Ready。Ready 前允许关闭（编辑区保持禁用；握手失败显示错误并可重试）；Ready 后，普通关闭必须先同步取消原生事件，再发送 `icetudio:close-requested`，携带本进程的请求 ID。重复关闭重发同一 ID，不创建多个确认框。

已有共享应用对话框时取消本次退出，保留当前输入并提示先完成/取消该对话框，不把退出问题排在它后面。前端先触发单值数字字段原有失焦行为，再读取当前检查结果，不用先前缓存的 dirty 布尔值推断。正在提交/查询/进行手势或事务结果未知时提示具体原因并取消本次退出；结果未知仍用现有“查询保存结果”处理，不因退出获得成功/失败结论。时间图检查尚未完成、最新检查点写入中或未获确认也阻止退出，提供重试；表单卸载后的在途草稿由工作区继续检查。仅有草稿且每项都已持久确认时询问“保留草稿并退出/继续编辑”，不会应用音乐；否则通用未持久草稿仍使用明确丢弃确认，不把旧检查点当作最新输入已保留。取消保留原草稿和基准修订。后台已保留但未打开的草稿不需要丢弃确认；无其他阻塞时可退出。

检查期间通过父级 inert 禁用普通编辑区，并单独禁用时间图模态中的输入/按钮/快捷键（顶层原生 dialog 可以越过祖先 inert，不能只依赖父级）；确认后再次读取检查结果。若对象或状态变化，取消本次退出，请用户检查后重试，不将旧确认套用于新草稿。仅匹配仍待处理 ID 的 ConfirmClose 才能启用退出许可并调用 Wails Quit；取消、过期 ID 和重复确认不得退出。原生 gate 用锁串行化状态，回调在锁外执行，避免 Quit 再入 ShouldQuit 时死锁。许可不向模型、CLI 或共享宿主暴露。

WebView 未响应时不自动当作“无草稿”放行；可重试关闭，不提供超时后自动丢弃。强制终止、OS 强杀/断电、WebView reload/崩溃不受可取消关闭握手保护；后续时间图增量只能恢复已确认检查点，最后未确认输入可能丢失，实际原生强杀/断电未验收。其他表单未因此获得持久恢复。正常退出前不主动停止其他运行；获准退出后沿用已有宿主清理。
